## Objective
Understand Git version control — manage uncommitted changes, staging, committing, branching, merging, and conflict resolution.

## Tools Used
- Git
- Git Bash
- GitHub

## Key Git Commands
```bash
git init
git status
git add .
git commit -m "message"
git branch branch-name
git checkout branch-name
git merge branch-name
```

## Procedure

### Step 1 - Uncommitted Changes
Made changes to a file without staging to observe `git status` output.

### Step 2 - Staging Changes
Used `git add` to stage the modified files.

### Step 3 - Commit Changes
Committed staged changes using `git commit -m`.

### Step 4 - Create Branch
Created a new feature branch using `git branch` and switched to it.

### Step 5 - Commit on Feature Branch
Made and committed changes on the feature branch.

### Step 6 - Merge Branches
Merged the feature branch back into main using `git merge`.

### Step 7 - Merge Conflict Resolution
Intentionally created a merge conflict and resolved it manually.
